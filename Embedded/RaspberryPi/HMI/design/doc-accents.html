Accent Palette Options

Four accent directions for the HMI, the fixed status colours they sit alongside, and the reasoning behind each choice.

Options 4 September 2026 Base “Control Room” Themes Dark + Light

The interface uses a single accent colour for everything interactive and selected — the active navigation tab, the control-source toggle, selected modes, links, values, and the LED glow. Everything else is either a neutral or one of the fixed status colours. Choosing the accent is therefore the one colour decision that sets the personality of the whole product, which is why it is presented on its own.

Two rules the accent must respect

First, the accent stays clearly distinct from the status language (green / amber / red / grey) so “this is interactive” never reads as “this is a warning.” Second — and for exactly that reason — amber is not offered as an accent: it is already the warning colour. All four options therefore sit on the cool side of the wheel.

The four options

Shown against the dark theme, where an accent reads most strongly. Each option lists its solid value plus the translucent fill and border tints derived from it.

Option ACyan#2AD4E6 · current

Cool, technical, instrument-like. The current direction. Reads as classic control-room / SCADA and pairs naturally with the charcoal ground. The safest, most expected choice for this domain.

Option BAzure#3B9BFF

A truer blue. Slightly more “software dashboard” than cyan while staying sober and calm. Very legible on both grounds; the most conventional-modern option.

Option CViolet#A480FF

Distinctive and contemporary. The most characterful option — it makes the product look considered rather than generic. Still calm enough for a control surface, with the most personality of the four.

Option DSteel#7F9BBF · muted

Quiet and utilitarian. A desaturated blue-grey that recedes and lets the status colours do all the talking. The most restrained option — best if the priority is calm, no-nonsense monitoring over visual identity.

The fixed status language

These four colours carry meaning and do not change with the accent. They are the same in every option and in both themes, so an operator reads state the same way regardless of the accent chosen.

Healthy
#1F9D52
Online, operating as commanded.
Warning
#C6810B
Attention needed, still running.
Fault
#D83A34
A failure requiring action.
Offline
#93A0AD
Not reporting / unknown.

Note the deliberate distance between every accent option and the amber warning and red fault hues — that separation is what keeps interactive elements from being mistaken for alarms.

Typography

  • IBM Plex Sans — all interface text, labels, and headings. An engineering-adjacent grotesque that suits an industrial control surface without feeling generic.
  • IBM Plex Mono — every piece of machine data: node IDs, IP addresses, registers, counts, raw values, timestamps. The switch to mono is what makes data read as data.

Choosing an option

Pick one letter — A, B, C or D. Only the accent tokens change; the status language, neutrals, layout, and typography stay exactly as they are, and the choice is applied across all five screens in both the dark and light themes.
